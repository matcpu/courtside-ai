### Resolved stale-draft overwrite

The original 5 → Preseason 7 → stale finish 5 defect was reproduced before repair. Each existing-season draft now stores a trusted `base_safety` snapshot generated from the authoritative league, full Preseason configuration (including `rules_version`) and ordered divisions. Capture and comparison run while holding the existing shared league row lock. `finish` compares the current snapshot after a lock wait and before any league mutation, then writes in the same transaction. Autosave cannot replace this baseline; missing or changed baselines fail closed. Browser-supplied snapshot data is ignored; direct baseline writes and direct helper execution are denied.

Regression coverage includes minimum/maximum roster, cutoff, accepted document types, retention, verification policy, division age bounds/category changes and ABA changes. Rejected finishes preserve complete records across 21 affected tables, including synthetic team/player rows, draft status, configuration and audit/history. Native tests observe a Preseason-first waiter rejecting after commit, a finish-first writer followed by the newer Preseason write, and a draft-open waiter capturing fresh settings. HTTP returns **409** with an instruction to close the draft, reload the league and review newer settings in a fresh edit; it does not silently merge, retry or discard the user's draft.

The local browser Auth/PostgREST service is a synthetic contract adapter. Native PostgreSQL proves database locking/RLS behavior, **not hosted Supabase Auth/Storage acceptance**, SMTP confirmation, physical Safari/Android compatibility or a load benchmark. No paid provider call is part of the repair tests.

Vercel's existing `courtside-ai` project was inspected read-only: no Git repository link, `gitProviderOptions.createDeployments=disabled`, and repository dispatch events disabled. The branch/PR can be pushed without a Vercel deployment. CI contains verification commands only, including the local SQL suite; it has no deployment or hosted-migration step.
